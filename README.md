# CargoMate – Firebase Migration Starter

This bundle gives you a Firebase-ready Flutter app structure (models, viewmodels, repositories, services),
plus Cloud Functions to **initialize** and **verify** Paystack transactions securely.

> ⚠️ You still need to run `flutterfire configure` to generate **lib/firebase_options.dart** for YOUR Firebase project.

## Quick Start

### 1) Flutter app

```bash
# Inside the project root
flutter pub get
dart pub global activate flutterfire_cli
flutterfire configure  # select your Firebase project & platforms (Android/iOS)
flutter run
```

### 2) Android/iOS setup (brief)
- Put **android/app/google-services.json** in place (from Firebase console).
- Put **ios/Runner/GoogleService-Info.plist** in place and `cd ios && pod install`.

### 3) Cloud Functions (Paystack)
```bash
cd functions
npm i
# Set your secret safely:
firebase functions:secrets:set PAYSTACK_SECRET_KEY
npm run build
firebase deploy --only functions
```

You’ll get two HTTPS endpoints:
- `paystackInit` → POST `{ amount, email, currency, metadata? }` → returns `{ authorization_url, reference }`
- `paystackVerify` → GET `?reference=...` → returns Paystack verification payload

### 4) Firestore Rules
Deploy the rules included in `firebase/firestore.rules`:

```bash
firebase deploy --only firestore:rules
```

## Notes

- **NEVER** hardcode your Paystack secret in the app. It lives only in **Cloud Functions** via `PAYSTACK_SECRET_KEY` secret.
- The client calls your functions to create the transaction and to verify after checkout.
- `payment_service.dart` expects the two endpoints and uses Firebase ID token if present.
- Adjust collection names if you prefer `profiles` over `users` – the repositories are easy to tweak.
- Replace any UI widgets (AppScaffold/PrimaryButton/etc.) with your existing implementations if names differ.
